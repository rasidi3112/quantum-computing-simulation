## نظرة عامة

‏Mini Quantum Lab تطبيق ويب تعليمي لاستكشاف أساسيات الحوسبة الكمية: بناء دوائر صغيرة بوابةً بوابة، ومراقبة متجه الحالة، ورؤية كل بت كمي على كرة بلوخ، وإجراء القياس، وإضافة الضوضاء، وتشغيل بعض البروتوكولات والخوارزميات المعروفة في الكتب الدراسية.

يحافظ الإصدار 2.0 على مظهر المشروع الأصلي وطريقة العمل به، ويستبدل ما تحته: حزمة محاكاة مستقلة لها اختبارات وحدات، واصطلاح واحد موثَّق لترتيب البتات الكمية، وقياس متسق فيزيائيًا، وتمثيلات مرئية جديدة. التدقيق الذي دفع إلى هذه التغييرات موجود في [`docs/AUDIT.md`](docs/AUDIT.md).

> هذا المشروع مستوحى من الأسلوب البصري لأدوات مثل IBM Quantum Composer و Qiskit. وهو مشروع تعليمي مستقل **غير تابع لشركة IBM ولا معتمد منها** ولا من أي جهة أخرى في مجال الحوسبة الكمية. يحاكي بتات كمية مثالية وأخرى مع ضوضاء على حاسوب كلاسيكي، ولا يتصل بعتاد كمي.

## التثبيت

يتطلب Python 3.11 أو أحدث (جرى الاختبار على 3.11 و 3.13).

```bash
git clone https://github.com/rasidi3112/quantum-computing-simulation.git
cd quantum-computing-simulation
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run main.py
```

ثم افتح <http://localhost:8501>.

اعتماديات التشغيل هي `numpy` و `streamlit` و `plotly`. أما حزمة المحاكاة نفسها (`quantum_lab` دون `visualization`) فتحتاج إلى NumPy فقط.

## الاستخدام

1. اختر **عدد البتات الكمية** من الشريط الجانبي (تغييره يبدأ دائرة جديدة فارغة).
2. اختر بوابة وبتًّا كميًا مستهدفًا ثم اضغط **Apply Gate**؛ وعند وجود بتّين كميين أو أكثر اختر التحكم والهدف ثم اضغط **Apply CNOT**.
3. اقرأ النتيجة في علامات التبويب:
   - **Lab**: مخطط الدائرة والاحتمالات والسعات والأطوار وجدول الحالة؛
   - **Bloch Sphere**: كرة لكل بت كمي؛
   - **Measurement**: ‏*Run Measurement* يأخذ عينات دون المساس بالحالة؛ أما *Measure Qubit* و *Measure All Qubits* فيجعلانها تنهار؛
   - **Entanglement**, **Noise**, **Algorithms**: عروض مستقلة. الزر *Load into Lab* ينسخ دائرة بيل إلى المختبر.
4. ‏**Reset System** يعيد الحالة إلى |0…0⟩ ويعيد تشغيل مولّد الأعداد العشوائية من البذرة.

الرسوم تفاعلية (تمرير المؤشر، التكبير، التدوير). زر الكاميرا في شريط أدوات الرسم يحفظ صورة PNG؛ وأزرار *Save …* تنزّل ملف HTML تفاعليًا مستقلًا.

### دوائر نموذجية

| الهدف | الخطوات | النتيجة المتوقعة |
|---|---|---|
| التراكب | 1 qubit: H → Q0 | P(0) = P(1) = 0.5; متجه بلوخ على +x |
| حالة بيل \|Φ+⟩ | 2 qubits: H → Q0, CNOT Q0 → Q1 | (\|00⟩ + \|11⟩)/√2; P(00) = P(11) = 0.5, P(01) = P(10) = 0; طول كلا متجهي بلوخ يساوي 0 |
| H·Z·H = X | 1 qubit: H, Z, H → Q0 | \|1⟩ |
| حالة GHZ | 3 qubits: H → Q0, CNOT Q0 → Q1, CNOT Q1 → Q2 | (\|000⟩ + \|111⟩)/√2 |
| الانهيار | حالة بيل ثم *Measure Qubit* على Q0 | \|00⟩ / \|11⟩; يصبح Q1 محدَّدًا |

```
q0: ──[H]──●──
           │
q1: ───────⊕──
```

### استخدام المحاكي من Python

```python
import numpy as np
from quantum_lab import Circuit, QuantumSimulator, gates

sim = QuantumSimulator(2)
sim.apply(gates.HADAMARD, [0])
sim.cnot(0, 1)
print(np.round(sim.state, 4))             # [0.7071 0 0 0.7071]
print(sim.sample_counts(1000, rng=42))    # [487 0 0 513] = counts of 00, 01, 10, 11
print(sim.measure_qubit(0, rng=7), sim.state)   # 0 [1 0 0 0]: collapsed to |00>

circuit = Circuit(2).gate("H", 0).cnot(0, 1).measure(0).measure(1)
print(circuit.draw())
print(circuit.run(rng=1).outcomes)        # {0: 0, 1: 0}; the two bits always agree
```

## الاصطلاحات الرياضية الكمية

**الحالة.** سجل من *n* بتًّا كميًا هو متجه مركّب من 2ⁿ سعة αᵢ يحقق Σ|αᵢ|² = 1، ويُهيَّأ على |0…0⟩.

**ترتيب البتات الكمية: big-endian في كل مكان.** البت الكمي 0 هو البت *الأقصى إلى اليسار* في تسمية الأساس والسلك *العلوي* في المخطط:

```
|q0 q1 … q(n-1)⟩      index = Σ_k q_k · 2^(n-1-k)      |ψ⟩ = |q0⟩ ⊗ |q1⟩ ⊗ … ⊗ |q(n-1)⟩
```

وعليه، مع بتّين كميين، تحوّل X على Q0 الحالة |00⟩ إلى |10⟩ (الفهرس 2). المصفوفة التي تؤثر في قائمة البتات `[a, b]` تعامل `a` على أنه البت الأعلى قيمة؛ وبالأخص `gates.CNOT` هي المصفوفة الخاصة بـ `[control, target]`. هذا هو اصطلاح الكتب الدراسية (Nielsen & Chuang). **أما Qiskit فيستخدم الترتيب المعاكس little-endian**؛ اعكس سلاسل البتات عند المقارنة.

**التطور.** يُفحص كل مؤثر للتأكد من أنه واحدي (U†U = I بتفاوت 10⁻¹⁰) قبل تطبيقه، ولا يُعاد تطبيع الحالة أبدًا أثناء التطور الواحدي. تؤكد الاختبارات أن المعيار يبقى ضمن 10⁻¹⁰ من 1 بعد 3000 بوابة.

**القياس (الأساس الحسابي):**

- *أخذ العينات بالطلقات* يسحب النتائج من P(i) = |αᵢ|². وهو ينمذج تحضير الحالة نفسها من جديد لكل طلقة؛ والحالة لا تتغير.
- *القياس الإسقاطي* للبت الكمي *k* يسحب m ∈ {0, 1} باحتمال P(m) = Σ_{i: bit k = m} |αᵢ|²، ثم يستبدل الحالة بـ P_m|ψ⟩ / √P(m). قياس جميع البتات يترك حالة أساس.
- *العشوائية.* البذرة الصحيحة تعطي نتائج قابلة للتكرار (`numpy.random.default_rng`). في التطبيق يستخدم أخذ العينات بالطلقات البذرة مباشرة (البذرة والحالة نفساهما ← المدرج التكراري نفسه)، أما القياسات الإسقاطية فتستهلك مولّدًا واحدًا يُعاد تشغيله عند إعادة الضبط وعند تغيير البذرة وعند تغيير حجم السجل.

**متجه بلوخ.** للبت الكمي *k* تعطي مصفوفة الكثافة المختزلة ρ_k = Tr_{others} |ψ⟩⟨ψ| المتجه r = (Tr ρ_kX, Tr ρ_kY, Tr ρ_kZ) حيث ρ_k = (I + r·σ)/2. يكون |r| = 1 للبت الكمي النقي، و |r| < 1 إذا كان متشابكًا مع بتات أخرى أو متأثرًا بالضوضاء، والنقاء هو Tr ρ_k² = (1 + |r|²)/2. السجل المتشابك ليس له متجه بلوخ واحد، لذلك لا يُرسم له متجه.

**الضوضاء.** بعد كل بوابة تؤثر القناة المختارة في كل بت كمي لمسته تلك البوابة (احتمال الخطأ *p* لكل تطبيق):

| القناة | التحويل |
|---|---|
| قلب البت | ρ → (1 − p)ρ + p XρX |
| قلب الطور | ρ → (1 − p)ρ + p ZρZ |
| إزالة الاستقطاب | ρ → (1 − p)ρ + (p/3)(XρX + YρY + ZρZ) |

بهذه الصياغة تضرب قناة إزالة الاستقطاب متجه بلوخ في 1 − 4p/3 (القيمة p = 3/4 تعطي الحالة المختلطة تمامًا). البتات الخاملة والقياسات خالية من الضوضاء. تُطوَّر مصفوفة الكثافة بدقة؛ والقياسات داخل دائرة فيها ضوضاء يُحسب متوسطها على نتائجها.

**الدقة (Fidelity).** ‏⟨ψ|ρ|ψ⟩ بالنسبة إلى مرجع نقي، ودقة أولمان (Tr √(√ρ σ √ρ))² في الحالة العامة.

## البوابات الكمية المدعومة

| البوابة | المصفوفة | التأثير |
|---|---|---|
| Identity (I) | [[1, 0], [0, 1]] | تترك البت الكمي دون تغيير |
| Pauli-X | [[0, 1], [1, 0]] | قلب البت \|0⟩ ↔ \|1⟩ |
| Pauli-Y | [[0, −i], [i, 0]] | Y\|0⟩ = i\|1⟩, Y\|1⟩ = −i\|0⟩ |
| Pauli-Z | [[1, 0], [0, −1]] | قلب الطور \|1⟩ → −\|1⟩ |
| Hadamard (H) | [[1, 1], [1, −1]]/√2 | \|0⟩ → \|+⟩, \|1⟩ → \|−⟩ |
| S | diag(1, i) | طور π/2 |
| T | diag(1, e^{iπ/4}) | طور π/4 |
| CNOT | \|0⟩⟨0\| ⊗ I + \|1⟩⟨1\| ⊗ X | تقلب الهدف إذا كان التحكم |1⟩ |

توفّر واجهة Python كذلك `rx` و `ry` و `rz` و `phase` ومؤثرات واحدية اختيارية على أي قائمة بتات كمية وبوابات بت كمي واحد متعددة التحكم؛ تستخدمها دائرتا النقل الآني وغروفر لكنها ليست في الشريط الجانبي بعد.

## الخوارزميات والبروتوكولات

- **حالات بيل.** بوابات X تختار الإدخال، ثم H و CNOT.
- **النقل الآني.** يحمل Q0 الحالة cos(θ/2)|0⟩ + e^{iφ}sin(θ/2)|1⟩، ويتشارك Q1 و Q2 زوج بيل. تطبّق أليس CNOT و H وتقيس Q0 و Q1؛ ويطبّق بوب X إذا كان m₁ = 1 و Z إذا كان m₀ = 1. الدقة المعروضة تُحسب من الحالة المحاكاة وتساوي 1 في الفروع الأربعة كلها.
- **Grover.** الأوراكل = X على البتات الصفرية للعنصر المعلَّم، ثم Z متعددة التحكم، ثم X مرة أخرى؛ الانتشار = Hⁿ Xⁿ (MCZ) Xⁿ Hⁿ. احتمال النجاح المحاكى يطابق sin²((2k+1)θ) حيث sin θ = 1/√N.
- **Deutsch–Jozsa.** يُبنى الأوراكل U_f|x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩ من جدول الحقيقة للدالة f. يوفّر التطبيق دوال ثابتة وزوجيات بتات مختارة ودوال متوازنة عشوائية.

عند الحد القديم وهو ثلاثة بتات كمية لا يوجد تسريع (التحقق من المدخلات يكلّف بضعة ميكروثوانٍ)؛ الفائدة أن السجلات الأكبر صارت عملية. تبقى كلفة المحاكاة تتضاعف مع كل بت كمي. هذه أداة تعليمية لسجلات صغيرة وليست محاكيًا للأغراض العامة.

## القيود المعروفة

- تتيح الواجهة من 1 إلى 6 بتات كمية؛ والبوابات في الشريط الجانبي هي I و X و Y و Z و H و S و T و CNOT. بوابات الدوران موجودة في واجهة Python فقط.
- القياس في الأساس الحسابي (Z) فقط.
- الضوضاء هي ضوضاء باولي على بت كمي واحد بعد البوابات. لا يوجد تخميد سعة ولا خطأ قراءة ولا ضوضاء أثناء الخمول ولا ضوضاء مترابطة.
- يبحث غروفر عن عنصر معلَّم واحد؛ ويُطبَّق أوراكل دويتش–جوزا كصندوق واحدي واحد بدل تفكيكه إلى بوابات أولية.
- الدائرة تقبل الإضافة فقط (لا تراجع ولا تحرير ولا سحب وإفلات).
- مخطط الدائرة نص ثابت العرض؛ والدوائر الطويلة جدًا تُمرَّر أفقيًا.
- العربية مترجمة لكن تخطيط الصفحة لا يُعكس من اليمين إلى اليسار.
- السلاسل الثمانون المضافة في 2.0 تُرجمت دون مراجعة من ناطقين أصليين؛ التصويبات مرحَّب بها.
- لا يوجد اتصال بعتاد كمي حقيقي ولا بخدمات سحابية.

## تغييرات عن 1.0 قد تؤثر فيك

- **نتائج CNOT تختلف لأن القديمة كانت خاطئة.** كان 1.0 يخلط بين ترتيبين للبتات الكمية، فكانت الدوائر التي تجمع بوابات البت الواحد مع CNOT تعطي حالات غير صحيحة (انظر `docs/AUDIT.md`، الملاحظة Q1).
- انتقل `QuantumSimulator` من `main.py` إلى `quantum_lab`. دوالّه في 1.0 (`apply_gate` و `get_probabilities` و `get_amplitudes` و `measure` و `reset` و `_expand_gate` و `_create_cnot_matrix`) باقية. المدخلات غير الصالحة تُطلق الآن `ValueError` أو `TypeError` بدل قبولها بصمت، و `state` للقراءة فقط، والمصفوفات غير الواحدية تُرفض.
- يظهر المدرج التكراري للقياس بعد الضغط على *Run Measurement* بدل إعادة توليده عند كل تفاعل.
- الرسوم تعتمد Plotly بدل Matplotlib. أزرار *Save …* تنزّل الآن HTML تفاعليًا؛ وتصدير PNG موجود في شريط أدوات كل رسم.
- أُزيلت `matplotlib` و `qiskit` غير المستخدمة من `requirements.txt`، وأُضيفت `plotly`.
