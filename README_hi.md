## परिचय

Mini Quantum Lab क्वांटम कंप्यूटिंग की बुनियादी बातें समझने के लिए एक शैक्षिक वेब एप्लिकेशन है: एक-एक गेट जोड़कर छोटे सर्किट बनाइए, स्टेट वेक्टर देखिए, हर क्यूबिट को ब्लॉख स्फीयर पर देखिए, मापन कीजिए, नॉइज़ जोड़िए और कुछ पाठ्यपुस्तक वाले प्रोटोकॉल और एल्गोरिदम चलाइए।

संस्करण 2.0 मूल प्रोजेक्ट का रूप और काम करने का तरीका बनाए रखता है और उसके नीचे का हिस्सा बदल देता है: यूनिट टेस्ट वाला अलग सिमुलेशन पैकेज, क्यूबिट क्रम की एक ही प्रलेखित परिपाटी, भौतिक रूप से सुसंगत मापन और नई विज़ुअलाइज़ेशन। जिस ऑडिट के कारण ये बदलाव हुए वह [`docs/AUDIT.md`](docs/AUDIT.md) में है।

> यह प्रोजेक्ट IBM Quantum Composer और Qiskit जैसे टूल की दृश्य शैली से प्रेरित है। यह एक स्वतंत्र शैक्षिक प्रोजेक्ट है और **IBM या किसी अन्य क्वांटम कंप्यूटिंग संस्था से संबद्ध या उनके द्वारा समर्थित नहीं है**। यह क्लासिकल कंप्यूटर पर आदर्श और नॉइज़ वाले क्यूबिट का सिमुलेशन करता है; क्वांटम हार्डवेयर से नहीं जुड़ता।

## उपयोग

1. साइडबार में **क्यूबिट की संख्या** चुनें (इसे बदलने पर नया, खाली सर्किट शुरू होता है)।
2. एक गेट और लक्ष्य क्यूबिट चुनकर **Apply Gate** दबाएँ; दो या अधिक क्यूबिट होने पर कंट्रोल और लक्ष्य चुनकर **Apply CNOT** दबाएँ।
3. परिणाम टैब में देखें:
   - **Lab**: सर्किट आरेख, प्रायिकताएँ, आयाम, फेज़, स्टेट तालिका;
   - **Bloch Sphere**: हर क्यूबिट के लिए एक गोला;
   - **Measurement**: *Run Measurement* स्टेट को छुए बिना शॉट का सैंपल लेता है; *Measure Qubit* / *Measure All Qubits* उसे कोलैप्स कर देते हैं;
   - **Entanglement**, **Noise**, **Algorithms**: स्वतंत्र प्रदर्शन। *Load into Lab* बेल सर्किट को लैब में कॉपी करता है।
4. **Reset System** |0…0⟩ पर लौटाता है और रैंडम जनरेटर को सीड से दोबारा शुरू करता है।

चार्ट इंटरैक्टिव हैं (होवर, ज़ूम, घुमाना)। चार्ट के टूलबार का कैमरा बटन PNG सहेजता है; *Save …* बटन एक स्वतंत्र इंटरैक्टिव HTML फ़ाइल डाउनलोड करते हैं।

### Python से सिम्युलेटर का उपयोग

```python
import numpy as np
from quantum_lab import Circuit, QuantumSimulator, gates

sim = QuantumSimulator(2)
sim.apply(gates.HADAMARD, [0])
sim.cnot(0, 1)
print(np.round(sim.state, 4))             # [0.7071 0 0 0.7071]
print(sim.sample_counts(1000, rng=42))    # [487 0 0 513] = counts of 00, 01, 10, 11
print(sim.measure_qubit(0, rng=7), sim.state)   # 0 [1 0 0 0]: collapsed to |00>

circuit = Circuit(2).gate("H", 0).cnot(0, 1).measure(0).measure(1)
print(circuit.draw())
print(circuit.run(rng=1).outcomes)        # {0: 0, 1: 0}; the two bits always agree
```

## क्वांटम गणितीय परिपाटियाँ

**स्टेट।** *n* क्यूबिट का रजिस्टर 2ⁿ आयामों αᵢ का सम्मिश्र वेक्टर है जिसमें Σ|αᵢ|² = 1 होता है और जो |0…0⟩ से आरंभ होता है।

**क्यूबिट क्रम: बिग-एंडियन, हर जगह।** क्यूबिट 0 बेसिस लेबल की *सबसे बाईं* बिट और आरेख की *सबसे ऊपर* की तार है:

```
|q0 q1 … q(n-1)⟩      index = Σ_k q_k · 2^(n-1-k)      |ψ⟩ = |q0⟩ ⊗ |q1⟩ ⊗ … ⊗ |q(n-1)⟩
```

इसलिए दो क्यूबिट में Q0 पर X, |00⟩ को |10⟩ (इंडेक्स 2) में बदल देता है। क्यूबिट सूची `[a, b]` पर कार्य करने वाली मैट्रिक्स `a` को सबसे महत्वपूर्ण बिट मानती है; विशेष रूप से `gates.CNOT`, `[control, target]` के लिए मैट्रिक्स है। यह पाठ्यपुस्तक (Nielsen & Chuang) की परिपाटी है। **Qiskit उलटा, लिटिल-एंडियन क्रम अपनाता है**; तुलना करते समय बिट स्ट्रिंग उलट दें।

**विकास।** हर ऑपरेटर को लागू करने से पहले उसकी यूनिटरिटी जाँची जाती है (U†U = I, सहनसीमा 10⁻¹⁰), और यूनिटरी विकास के दौरान स्टेट को कभी दोबारा नॉर्मलाइज़ नहीं किया जाता। टेस्ट पुष्टि करते हैं कि 3000 गेट के बाद भी नॉर्म 1 से 10⁻¹⁰ के भीतर रहता है।

**मापन (कम्प्यूटेशनल बेसिस):**

- *शॉट सैंपलिंग* P(i) = |αᵢ|² से परिणाम निकालती है। यह हर शॉट के लिए वही स्टेट दोबारा तैयार करने का मॉडल है; स्टेट नहीं बदलती।
- क्यूबिट *k* का *प्रोजेक्टिव मापन* P(m) = Σ_{i: bit k = m} |αᵢ|² के साथ m ∈ {0, 1} निकालता है, फिर स्टेट को P_m|ψ⟩ / √P(m) से बदल देता है। सभी क्यूबिट मापने पर एक बेसिस स्टेट बचती है।
- *यादृच्छिकता।* पूर्णांक सीड दोहराने योग्य परिणाम देता है (`numpy.random.default_rng`)। ऐप में शॉट सैंपलिंग सीड का सीधे उपयोग करती है (समान सीड और स्टेट → समान हिस्टोग्राम), जबकि प्रोजेक्टिव मापन एक ही जनरेटर का उपयोग करते हैं जो रीसेट पर, सीड बदलने पर और रजिस्टर का आकार बदलने पर दोबारा शुरू होता है।

**ब्लॉख वेक्टर।** क्यूबिट *k* के लिए रिड्यूस्ड डेंसिटी मैट्रिक्स ρ_k = Tr_{others} |ψ⟩⟨ψ| से r = (Tr ρ_kX, Tr ρ_kY, Tr ρ_kZ) मिलता है, जहाँ ρ_k = (I + r·σ)/2। शुद्ध क्यूबिट के लिए |r| = 1, अन्य क्यूबिट से एंटैंगल्ड या नॉइज़ से प्रभावित होने पर |r| < 1, और शुद्धता Tr ρ_k² = (1 + |r|²)/2 होती है। एंटैंगल्ड रजिस्टर का कोई एक ब्लॉख वेक्टर नहीं होता, इसलिए कोई नहीं बनाया जाता।

**नॉइज़।** हर गेट के बाद चुना गया चैनल उस गेट से प्रभावित प्रत्येक क्यूबिट पर कार्य करता है (प्रति प्रयोग त्रुटि प्रायिकता *p*):

| चैनल | मैप |
|---|---|
| बिट फ्लिप | ρ → (1 − p)ρ + p XρX |
| फेज़ फ्लिप | ρ → (1 − p)ρ + p ZρZ |
| डीपोलराइज़िंग | ρ → (1 − p)ρ + (p/3)(XρX + YρY + ZρZ) |

इस पैरामीट्राइज़ेशन में डीपोलराइज़िंग चैनल ब्लॉख वेक्टर को 1 − 4p/3 से गुणा करता है (p = 3/4 अधिकतम मिश्रित स्टेट है)। निष्क्रिय क्यूबिट और मापन नॉइज़-रहित हैं। डेंसिटी मैट्रिक्स का विकास सटीक रूप से होता है; नॉइज़ वाले सर्किट के भीतर के मापनों का औसत उनके परिणामों पर लिया जाता है।

**फिडेलिटी।** शुद्ध संदर्भ के सापेक्ष ⟨ψ|ρ|ψ⟩, और सामान्य रूप से उलमान फिडेलिटी (Tr √(√ρ σ √ρ))²।

## समर्थित क्वांटम गेट

| गेट | मैट्रिक्स | क्रिया |
|---|---|---|
| Identity (I) | [[1, 0], [0, 1]] | क्यूबिट को अपरिवर्तित छोड़ता है |
| Pauli-X | [[0, 1], [1, 0]] | बिट फ्लिप \|0⟩ ↔ \|1⟩ |
| Pauli-Y | [[0, −i], [i, 0]] | Y\|0⟩ = i\|1⟩, Y\|1⟩ = −i\|0⟩ |
| Pauli-Z | [[1, 0], [0, −1]] | फेज़ फ्लिप \|1⟩ → −\|1⟩ |
| Hadamard (H) | [[1, 1], [1, −1]]/√2 | \|0⟩ → \|+⟩, \|1⟩ → \|−⟩ |
| S | diag(1, i) | फेज़ π/2 |
| T | diag(1, e^{iπ/4}) | फेज़ π/4 |
| CNOT | \|0⟩⟨0\| ⊗ I + \|1⟩⟨1\| ⊗ X | कंट्रोल |1⟩ होने पर लक्ष्य को पलटता है |

Python API में इसके अतिरिक्त `rx`, `ry`, `rz`, `phase`, किसी भी क्यूबिट सूची पर मनचाहे यूनिटरी और बहु-नियंत्रित एकल-क्यूबिट गेट उपलब्ध हैं; इनका उपयोग टेलीपोर्टेशन और ग्रोवर सर्किट में होता है, पर ये अभी साइडबार में नहीं हैं।

## एल्गोरिदम और प्रोटोकॉल

- **बेल स्टेट।** X गेट इनपुट चुनते हैं, फिर H और CNOT।
- **टेलीपोर्टेशन।** Q0 में cos(θ/2)|0⟩ + e^{iφ}sin(θ/2)|1⟩ होती है, Q1–Q2 एक बेल जोड़ी साझा करते हैं। ऐलिस CNOT और H लगाकर Q0, Q1 को मापती है; बॉब m₁ = 1 होने पर X और m₀ = 1 होने पर Z लगाता है। दिखाई गई फिडेलिटी सिमुलेट की गई स्टेट से निकाली जाती है और चारों शाखाओं में 1 है।
- **Grover.** ओरेकल = चिह्नित आइटम की शून्य बिट्स पर X, बहु-नियंत्रित Z, फिर से X; डिफ्यूज़न = Hⁿ Xⁿ (MCZ) Xⁿ Hⁿ। सिमुलेट की गई सफलता प्रायिकता sin²((2k+1)θ), sin θ = 1/√N से मेल खाती है।
- **Deutsch–Jozsa.** ओरेकल U_f|x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩, f की सत्य तालिका से बनाया जाता है। ऐप में स्थिर फ़ंक्शन, चुनी गई बिट्स की पैरिटी और यादृच्छिक संतुलित फ़ंक्शन मिलते हैं।

## प्रदर्शन और सीमाएँ

| राशि | स्टेट वेक्टर | डेंसिटी मैट्रिक्स |

| 3 | 35 µs | 40 µs | 0.9× |
| 6 | 100 µs | 43 µs | 2× |
| 8 | 553 µs | 44 µs | 13× |
| 10 | 7.6 ms | 49 µs | 155× |

पुरानी तीन-क्यूबिट सीमा पर कोई गति-वृद्धि नहीं है (इनपुट जाँच में कुछ माइक्रोसेकंड लगते हैं); लाभ यह है कि बड़े रजिस्टर व्यावहारिक हो गए। सिमुलेशन की लागत अब भी हर क्यूबिट के साथ दोगुनी होती है। यह छोटे रजिस्टरों के लिए एक शिक्षण उपकरण है, सामान्य-उद्देश्य सिम्युलेटर नहीं।

## ज्ञात सीमाएँ

- इंटरफ़ेस 1–6 क्यूबिट देता है; साइडबार के गेट I, X, Y, Z, H, S, T और CNOT हैं। रोटेशन गेट केवल Python API में हैं।
- मापन केवल कम्प्यूटेशनल (Z) बेसिस में होता है।
- नॉइज़ गेट के बाद की एकल-क्यूबिट पाउली नॉइज़ है। एम्प्लीट्यूड डैम्पिंग, रीडआउट त्रुटि, निष्क्रिय अवस्था की नॉइज़ और सहसंबद्ध नॉइज़ नहीं है।
- ग्रोवर एक ही चिह्नित आइटम खोजता है; डॉइच–जोज़ा ओरेकल को मूल गेटों में तोड़ने के बजाय एक यूनिटरी बॉक्स के रूप में लगाया जाता है।
- सर्किट में केवल जोड़ा जा सकता है (अनडू, संपादन, ड्रैग-एंड-ड्रॉप नहीं)।
- सर्किट आरेख मोनोस्पेस टेक्स्ट है; बहुत लंबे सर्किट क्षैतिज रूप से स्क्रॉल होते हैं।
- अरबी का अनुवाद है, पर पेज का लेआउट दाएँ-से-बाएँ नहीं पलटता।
- 2.0 में जोड़ी गई 80 स्ट्रिंग का अनुवाद मूल भाषियों की समीक्षा के बिना हुआ है; सुधारों का स्वागत है।
- वास्तविक क्वांटम हार्डवेयर या क्लाउड बैक एंड से कोई कनेक्शन नहीं।

## 1.0 से हुए बदलाव जो आपको प्रभावित कर सकते हैं

- **CNOT के परिणाम अलग हैं क्योंकि पुराने गलत थे।** 1.0 में क्यूबिट के दो क्रम मिल गए थे, इसलिए एकल-क्यूबिट गेट और CNOT को मिलाने वाले सर्किट गलत स्टेट देते थे (देखें `docs/AUDIT.md`, निष्कर्ष Q1)।
- `QuantumSimulator`, `main.py` से `quantum_lab` में चला गया है। इसकी 1.0 वाली विधियाँ (`apply_gate`, `get_probabilities`, `get_amplitudes`, `measure`, `reset`, `_expand_gate`, `_create_cnot_matrix`) बनी हुई हैं। अमान्य इनपुट अब चुपचाप स्वीकार होने के बजाय `ValueError`/`TypeError` देता है, `state` केवल-पठनीय है और गैर-यूनिटरी मैट्रिक्स अस्वीकार होती हैं।
- मापन हिस्टोग्राम हर इंटरैक्शन पर दोबारा बनने के बजाय *Run Measurement* दबाने के बाद दिखता है।
- चार्ट Matplotlib के बजाय Plotly से बनते हैं। *Save …* बटन अब इंटरैक्टिव HTML डाउनलोड करते हैं; PNG एक्सपोर्ट हर चार्ट के टूलबार में है।
- `matplotlib` और अप्रयुक्त `qiskit` को `requirements.txt` से हटाया गया; `plotly` जोड़ा गया।

## Streamlit Community Cloud पर डिप्लॉय

1. रिपॉज़िटरी (या अपना फ़ोर्क) GitHub पर पुश करें।
2. GitHub से <https://share.streamlit.io> पर साइन इन करें और नया ऐप बनाएँ।
3. रिपॉज़िटरी और ब्रांच चुनें, और main file path को `main.py` पर सेट करें।
4. advanced settings में Python 3.11 या नया चुनें, फिर डिप्लॉय करें।

निर्भरताएँ `requirements.txt` से इंस्टॉल होती हैं; किसी सीक्रेट या एनवायरनमेंट वेरिएबल की ज़रूरत नहीं। ये चरण प्लेटफ़ॉर्म के अनुभव के आधार पर लिखे गए हैं और इस रिलीज़ की तैयारी के समय इन्हें उसके वर्तमान दस्तावेज़ों से मिलाया नहीं जा सका। यदि स्क्रीन अलग दिखें तो यह देखें: <https://docs.streamlit.io/deploy/streamlit-community-cloud>.

`.devcontainer` कॉन्फ़िगरेशन Streamlit को CORS और XSRF सुरक्षा बंद करके शुरू करता है, जो GitHub Codespaces की पोर्ट फ़ॉरवर्डिंग के लिए आवश्यक है। सार्वजनिक डिप्लॉयमेंट में इन विकल्पों का उपयोग न करें।
