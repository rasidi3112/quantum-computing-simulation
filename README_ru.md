## Обзор

Mini Quantum Lab: учебное веб-приложение для знакомства с основами квантовых вычислений. В нём можно собирать небольшие схемы вентиль за вентилем, наблюдать вектор состояния, смотреть на каждый кубит на сфере Блоха, выполнять измерения, добавлять шум и запускать несколько классических протоколов и алгоритмов.

Версия 2.0 сохраняет внешний вид и порядок работы исходного проекта, но заменяет то, что находится внутри: отдельный пакет симуляции с модульными тестами, единое задокументированное соглашение о порядке кубитов, физически корректное измерение и новые визуализации. Аудит, послуживший причиной изменений, находится в [`docs/AUDIT.md`](docs/AUDIT.md).

> Проект вдохновлён визуальным стилем таких инструментов, как IBM Quantum Composer и Qiskit. Это независимый учебный проект, он **не связан с IBM и не одобрен IBM** или какой-либо другой организацией в области квантовых вычислений. Он моделирует идеальные и зашумлённые кубиты на классическом компьютере и не подключается к квантовому оборудованию.

## Установка

Требуется Python 3.11 или новее (проверено на 3.11 и 3.13).

```bash
git clone https://github.com/rasidi3112/quantum-computing-simulation.git
cd quantum-computing-simulation
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run main.py
```

Затем откройте <http://localhost:8501>.

Зависимости времени выполнения: `numpy`, `streamlit` и `plotly`. Самому пакету симуляции (`quantum_lab`, без `visualization`) нужен только NumPy.

## Использование

1. Выберите **количество кубитов** на боковой панели (изменение начинает новую пустую схему).
2. Выберите вентиль и целевой кубит и нажмите **Apply Gate**; при двух и более кубитах выберите управляющий и целевой кубиты и нажмите **Apply CNOT**.
3. Смотрите результат на вкладках:
   - **Lab**: диаграмма схемы, вероятности, амплитуды, фазы, таблица состояния;
   - **Bloch Sphere**: по одной сфере на кубит;
   - **Measurement**: *Run Measurement* делает выборку, не изменяя состояние; *Measure Qubit* / *Measure All Qubits* вызывают его коллапс;
   - **Entanglement**, **Noise**, **Algorithms**: самостоятельные демонстрации. *Load into Lab* копирует схему Белла в лабораторию.
4. **Reset System** возвращает |0…0⟩ и перезапускает генератор случайных чисел от зерна.

Графики интерактивны (наведение, масштаб, вращение). Кнопка с камерой на панели инструментов графика сохраняет PNG; кнопки *Save …* скачивают самостоятельный интерактивный HTML-файл.

### Примеры схем

| Цель | Шаги | Ожидаемый результат |
|---|---|---|
| Суперпозиция | 1 qubit: H → Q0 | P(0) = P(1) = 0.5; вектор Блоха направлен по +x |
| Состояние Белла \|Φ+⟩ | 2 qubits: H → Q0, CNOT Q0 → Q1 | (\|00⟩ + \|11⟩)/√2; P(00) = P(11) = 0.5, P(01) = P(10) = 0; оба вектора Блоха имеют длину 0 |
| H·Z·H = X | 1 qubit: H, Z, H → Q0 | \|1⟩ |
| Состояние ГХЦ | 3 qubits: H → Q0, CNOT Q0 → Q1, CNOT Q1 → Q2 | (\|000⟩ + \|111⟩)/√2 |
| Коллапс | Состояние Белла, затем *Measure Qubit* Q0 | \|00⟩ / \|11⟩; Q1 теперь определён |

```
q0: ──[H]──●──
           │
q1: ───────⊕──
```

### Использование симулятора из Python

```python
import numpy as np
from quantum_lab import Circuit, QuantumSimulator, gates

sim = QuantumSimulator(2)
sim.apply(gates.HADAMARD, [0])
sim.cnot(0, 1)
print(np.round(sim.state, 4))             # [0.7071 0 0 0.7071]
print(sim.sample_counts(1000, rng=42))    # [487 0 0 513] = counts of 00, 01, 10, 11
print(sim.measure_qubit(0, rng=7), sim.state)   # 0 [1 0 0 0]: collapsed to |00>

circuit = Circuit(2).gate("H", 0).cnot(0, 1).measure(0).measure(1)
print(circuit.draw())
print(circuit.run(rng=1).outcomes)        # {0: 0, 1: 0}; the two bits always agree
```

## Математические соглашения

**Состояние.** Регистр из *n* кубитов задаётся комплексным вектором из 2ⁿ амплитуд αᵢ с Σ|αᵢ|² = 1 и инициализируется в |0…0⟩.

**Порядок кубитов: big-endian, везде.** Кубит 0 является *крайним левым* битом базисной метки и *верхней* линией диаграммы:

```
|q0 q1 … q(n-1)⟩      index = Σ_k q_k · 2^(n-1-k)      |ψ⟩ = |q0⟩ ⊗ |q1⟩ ⊗ … ⊗ |q(n-1)⟩
```

Поэтому для двух кубитов X на Q0 превращает |00⟩ в |10⟩ (индекс 2). Матрица, действующая на список кубитов `[a, b]`, считает `a` старшим битом; в частности, `gates.CNOT` есть матрица для `[control, target]`. Это соглашение из учебников (Нильсен и Чанг). **В Qiskit используется обратный порядок, little-endian**; при сравнении разворачивайте битовые строки.

**Эволюция.** Каждый оператор проверяется на унитарность (U†U = I, допуск 10⁻¹⁰) перед применением, а состояние никогда не перенормируется в ходе унитарной эволюции. Тесты подтверждают, что после 3000 вентилей норма отличается от 1 менее чем на 10⁻¹⁰.

**Измерение (вычислительный базис):**

- *Серия выстрелов* выбирает исходы из P(i) = |αᵢ|². Она моделирует повторное приготовление того же состояния для каждого выстрела; состояние не меняется.
- *Проективное измерение* кубита *k* выбирает m ∈ {0, 1} с P(m) = Σ_{i: bit k = m} |αᵢ|², после чего состояние заменяется на P_m|ψ⟩ / √P(m). Измерение всех кубитов оставляет базисное состояние.
- *Случайность.* Целочисленное зерно даёт воспроизводимые результаты (`numpy.random.default_rng`). В приложении серия выстрелов использует зерно напрямую (одинаковые зерно и состояние → одинаковая гистограмма), а проективные измерения расходуют один генератор, который перезапускается при сбросе, при смене зерна и при изменении размера регистра.

**Вектор Блоха.** Для кубита *k* редуцированная матрица плотности ρ_k = Tr_{others} |ψ⟩⟨ψ| даёт r = (Tr ρ_kX, Tr ρ_kY, Tr ρ_kZ), где ρ_k = (I + r·σ)/2. |r| = 1 для чистого кубита, |r| < 1, если он запутан с другими кубитами или подвержен шуму, а чистота равна Tr ρ_k² = (1 + |r|²)/2. У запутанного регистра нет единого вектора Блоха, поэтому он не рисуется.

**Шум.** После каждого вентиля выбранный канал действует на каждый кубит, затронутый этим вентилем (вероятность ошибки *p* на одно применение):

| Канал | Отображение |
|---|---|
| Инверсия бита | ρ → (1 − p)ρ + p XρX |
| Инверсия фазы | ρ → (1 − p)ρ + p ZρZ |
| Деполяризующий | ρ → (1 − p)ρ + (p/3)(XρX + YρY + ZρZ) |

При такой параметризации деполяризующий канал масштабирует вектор Блоха на 1 − 4p/3 (p = 3/4 соответствует максимально смешанному состоянию). Простаивающие кубиты и измерения считаются бесшумными. Матрица плотности эволюционирует точно; измерения внутри зашумлённой схемы усредняются по исходам.

**Точность (fidelity).** ⟨ψ|ρ|ψ⟩ относительно чистого эталона и точность Ульмана (Tr √(√ρ σ √ρ))² в общем случае.

## Поддерживаемые квантовые вентили

| Вентиль | Матрица | Действие |
|---|---|---|
| Identity (I) | [[1, 0], [0, 1]] | оставляет кубит без изменений |
| Pauli-X | [[0, 1], [1, 0]] | инверсия бита \|0⟩ ↔ \|1⟩ |
| Pauli-Y | [[0, −i], [i, 0]] | Y\|0⟩ = i\|1⟩, Y\|1⟩ = −i\|0⟩ |
| Pauli-Z | [[1, 0], [0, −1]] | инверсия фазы \|1⟩ → −\|1⟩ |
| Hadamard (H) | [[1, 1], [1, −1]]/√2 | \|0⟩ → \|+⟩, \|1⟩ → \|−⟩ |
| S | diag(1, i) | фаза π/2 |
| T | diag(1, e^{iπ/4}) | фаза π/4 |
| CNOT | \|0⟩⟨0\| ⊗ I + \|1⟩⟨1\| ⊗ X | инвертирует целевой кубит, если управляющий равен |1⟩ |

API на Python дополнительно предоставляет `rx`, `ry`, `rz`, `phase`, произвольные унитарные операции над любым списком кубитов и многократно управляемые однокубитные вентили; они используются в схемах телепортации и Гровера, но пока отсутствуют на боковой панели.

## Алгоритмы и протоколы

- **Состояния Белла.** Вентили X выбирают вход, затем H и CNOT.
- **Телепортация.** Q0 несёт cos(θ/2)|0⟩ + e^{iφ}sin(θ/2)|1⟩, Q1–Q2 разделяют пару Белла. Алиса применяет CNOT и H и измеряет Q0 и Q1; Боб применяет X, если m₁ = 1, и Z, если m₀ = 1. Показанная точность вычисляется по смоделированному состоянию и равна 1 во всех четырёх ветвях.
- **Grover.** Оракул = X на нулевых битах отмеченного элемента, многократно управляемый Z, снова X; диффузия = Hⁿ Xⁿ (MCZ) Xⁿ Hⁿ. Смоделированная вероятность успеха совпадает с sin²((2k+1)θ), sin θ = 1/√N.
- **Deutsch–Jozsa.** Оракул U_f|x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩ строится по таблице истинности f. Приложение предлагает постоянные функции, чётности выбранных битов и случайные сбалансированные функции.

## Известные ограничения

- Интерфейс предлагает 1–6 кубитов; на боковой панели доступны вентили I, X, Y, Z, H, S, T и CNOT. Вентили вращения есть только в API на Python.
- Измерение выполняется только в вычислительном базисе (Z).
- Шум представляет собой однокубитный шум Паули после вентилей. Нет затухания амплитуды, ошибок считывания, шума простоя и коррелированного шума.
- Гровер ищет один отмеченный элемент; оракул Дойча–Йожи применяется как один унитарный блок, а не раскладывается на элементарные вентили.
- Схему можно только дополнять (нет отмены, редактирования и перетаскивания).
- Диаграмма схемы представляет собой моноширинный текст; очень длинные схемы прокручиваются по горизонтали.
- Арабский язык переведён, но макет страницы не зеркалируется справа налево.
- 80 строк, добавленных в 2.0, переведены без проверки носителями языка; исправления приветствуются.
- Нет подключения к реальному квантовому оборудованию или облачным сервисам.

## Изменения по сравнению с 1.0, которые могут вас затронуть

- **Результаты CNOT отличаются, потому что прежние были неверными.** В 1.0 смешивались два порядка кубитов, поэтому схемы, сочетавшие однокубитные вентили с CNOT, давали неправильные состояния (см. `docs/AUDIT.md`, пункт Q1).
- `QuantumSimulator` перенесён из `main.py` в `quantum_lab`. Его методы из 1.0 (`apply_gate`, `get_probabilities`, `get_amplitudes`, `measure`, `reset`, `_expand_gate`, `_create_cnot_matrix`) сохранены. Некорректный ввод теперь вызывает `ValueError`/`TypeError`, а не принимается молча, `state` доступен только для чтения, а неунитарные матрицы отклоняются.
- Гистограмма измерений появляется после нажатия *Run Measurement*, а не пересоздаётся при каждом действии.
- Графики строятся в Plotly вместо Matplotlib. Кнопки *Save …* теперь скачивают интерактивный HTML; экспорт в PNG находится на панели инструментов каждого графика.
- Из `requirements.txt` удалены `matplotlib` и неиспользуемый `qiskit`; добавлен `plotly`.

## Развёртывание в Streamlit Community Cloud

1. Отправьте репозиторий (или свой форк) на GitHub.
2. Войдите на <https://share.streamlit.io> через GitHub и создайте новое приложение.
3. Выберите репозиторий и ветку и укажите в main file path значение `main.py`.
4. В advanced settings выберите Python 3.11 или новее и выполните развёртывание.

Зависимости устанавливаются из `requirements.txt`; секреты и переменные окружения не нужны. Эти шаги написаны по опыту работы с платформой, и при подготовке этого выпуска их не удалось сверить с актуальной документацией. Если экраны отличаются, следуйте <https://docs.streamlit.io/deploy/streamlit-community-cloud>.

Конфигурация `.devcontainer` запускает Streamlit с отключённой защитой CORS и XSRF, что требуется для проброса портов в GitHub Codespaces. Не используйте эти параметры при публичном развёртывании.
